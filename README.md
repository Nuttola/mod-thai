# ดอกตีนเป็ดหอมแฮง

> “แปลนาน แปลอยู่ แปลต่อ”

เว็บรวมมอดแปลไทยสำหรับเกมอินดี้ — ซับไตเติลและเมนูภาษาไทย
พร้อมวิธีติดตั้ง ลิงก์ดาวน์โหลดต้นทาง และลิงก์ซื้อเกมถูกลิขสิทธิ์

## ในเว็บมีอะไร

| หน้า | รายละเอียด |
| --- | --- |
| **หน้าแรก** | มอดล่าสุด มอดยอดนิยม เกี่ยวกับผม และช่องทางติดตาม |
| **ผลงานทั้งหมด** | รวมทุกมอด พร้อมค้นหาและกรองตามสถานะ |
| **รายละเอียดมอด** | คำอธิบาย ภาพในเกม วิดีโอรีวิว วิธีติดตั้ง และสิ่งที่ต้องมี |
| **สนับสนุน** | QR พร้อมเพย์ |

สถานะของแต่ละมอด: 🟢 พร้อมโหลด · 🟡 กำลังแปล · 🔴 มีปัญหา · ⚪ เร็ว ๆ นี้

## หลักการ

- **ไม่โฮสต์ไฟล์มอด** — ทุกปุ่มดาวน์โหลดชี้ไปยังแหล่งต้นทาง
- **ไม่มีโฆษณา** ไม่มีระบบสมาชิก และไม่เก็บข้อมูลผู้ใช้
- ทุกมอดลองเล่นจบก่อนปล่อย และถอนการติดตั้งได้โดยไม่ทิ้งไฟล์ขยะ

## เทคโนโลยี

- [Astro](https://astro.build) 7 — static site ไม่มี backend
- GitHub Pages + GitHub Actions
- ฟอนต์ Kanit, Noto Sans Thai, Sriracha (SIL Open Font License)

## โครงสร้าง

```
src/content/mods/   ← ข้อมูลมอด (1 ไฟล์ต่อมอด)
src/data/           ← ข้อมูลแบรนด์ โซเชียล และสถานะ
src/pages/          ← หน้าเว็บทั้งหมด
public/img/         ← รูปปก รูปในเกม และ QR
```
